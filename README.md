# 🎲 Cool Dice App

A cool and rich 3D dice roller application with beautiful animations and statistics tracking.

## Features

- 🎲 **3D Dice Rolling** - Realistic 3D dice with physics simulation using Three.js and Cannon-es
- 🎨 **Cool UI Design** - Modern dark theme with gradient effects and smooth animations
- 📊 **Statistics Tracking** - Track your rolls with average, min, and max statistics
- 📜 **Roll History** - View your recent rolls with timestamps
- 🔄 **Multiple Dice Types** - Support for D6 and D20 dice
- 📱 **Responsive Design** - Works perfectly on desktop and mobile devices

## Tech Stack

- **Framework**: SvelteKit 5
- **3D Rendering**: Three.js
- **Physics**: Cannon-es
- **Language**: TypeScript
- **Styling**: Svelte CSS with modern CSS features
- **Deployment**: GitHub Pages

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Usage

1. **Select Dice Type**: Click "Switch to D20" or "Switch to D6" to change dice type
2. **Roll Dice**: Click the "Roll Dice" button to roll the 3D dice
3. **View Results**: See your roll result with a beautiful animation
4. **Check Statistics**: View average, minimum, and maximum rolls for each dice type
5. **Review History**: See your recent rolls in the history panel
